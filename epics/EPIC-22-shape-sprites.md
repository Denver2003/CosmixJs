# EPIC-22 Shape Sprites

## Goal
Перевести отрисовку фигур на спрайты (PNG), с отдельными пакетами по цветам и возможностью менять пак.

## Scope
- Генерация placeholder-спрайтов для всех фигур
- Привязка спрайтов к Matter.js bodies
- Учет цвета: отдельный pack на каждый цвет
- Шаблонная загрузка паков из каталога

## Out of scope
- Финальный арт
- UI для выбора паков

## Done when
- Фигуры рисуются спрайтами вместо контуров
- Пакеты подменяются без правок кода
