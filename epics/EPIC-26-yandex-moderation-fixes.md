# EPIC-26 Yandex Moderation Fixes

## Goal
Исправить замечания модерации Яндекс.Игр в части изменений внутри игры.

## Scope
- Привести название игры к канону в UI и метаданных страницы (RU/EN).
- Локализовать все хардкод‑тексты в игре (combo, level up, overlays, HUD, бонусы).
- Заменить Home кнопку Play (картинка) на текстовую кнопку.
- Запретить выделение/контекстное меню в игровом поле.
- SDK: корректная загрузка, Game Ready, авторизация только по действию пользователя.
- Одноразовый prompt авторизации после первого Game Over для неавторизованных.

## Out of scope
- Скриншоты, видео, SEO-тексты и прочие материалы карточки игры.
- Включение покупок через консоль/разрешение от Yandex.

## Done when
- Игра проходит модерацию по замечаниям, относящимся к игровому коду.
