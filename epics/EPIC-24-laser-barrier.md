# EPIC-24 Laser Barrier Death Line

## Goal
Заменить простую линию смерти на читаемый sci‑fi лазерный барьер, отрисованный в Canvas без спрайтов.

## Scope
- Реализация `drawLaserBarrier(ctx, y, width, timeSec, danger, color)`.
- Расчет `danger` (0..1) по высоте стека.
- Рендер лазера вместо текущей линии.
- Параметры для тюнинга (толщина, интенсивность, сегменты).

## Out of scope
- Спрайты.
- Шейдеры.
- Отдельный UI.

## Done when
- Барьер заметен на любом фоне.
- Интенсивность повышается при росте danger.
- Плавный пульс, скан‑сегменты, искры на критике.
