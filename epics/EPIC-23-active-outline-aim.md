# EPIC-23 Active Outline + Aim Guides

## Goal
Улучшить читаемость активной фигуры: добавить белый halo-обводки и направляющие по границам фигуры.

## Scope
- Halo: второй проход outline-спрайта для активной фигуры (+2px, alpha 0.35).
- Aim guides: две тонкие градиентные вертикальные линии по левому/правому краю активной фигуры.
- Параметризовать толщину/альфу/длину.

## Out of scope
- Новый арт или отдельные sprite-слои.
- UI переключатели.

## Done when
- Активная фигура визуально выделяется halo.
- Направляющие корректно следуют за фигурой и исчезают при сбросе.
