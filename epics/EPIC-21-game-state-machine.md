# EPIC-21 Game State Machine

## Goal
Сделать единый контроллер игровых состояний, чтобы исключить зависания и расхождения при паузе, переходах между экранами и Game Over.

## Scope
- Явные состояния: GAMEPLAY / PAUSED / GAMEOVER / SHELL
- Централизованные переходы и проверка допустимых переходов
- Хранение причины паузы (manual/auto/focus/shell)
- Синхронизация UI/таймеров при смене состояния
- Интеграция с текущими вызовами pause/game over/shell

## Out of scope
- Реклама (interstitial/rewarded)
- Экономика и магазин

## Done when
- Нет зависаний при переключении экранов
- Невозможны недопустимые переходы (например RESUME из GAMEOVER)
- Все переходы логируются и воспроизводимы
