# PLAN_EPIC_22 — Shape Sprites

- [x] Шаг 1: Зафиксировать математику совпадения спрайта и тела + точки привязки для каждой фигуры (в плане).
  - Общая формула отрисовки: для тела с позицией P=(x,y) и углом θ:
    - ctx.translate(x, y); ctx.rotate(θ);
    - drawImage(sprite, -w/2, -h/2, w, h) при origin в центре спрайта.
  - Математика совпадения: спрайт создается в локальной системе фигуры, где (0,0) = centroid геометрии тела.
    - Вершины локальные Vi = (xi, yi) используются при создании тела.
    - Центроид C = (Σxi/n, Σyi/n) для вершин (или центр масс у Matter).
    - PNG рисуется так, чтобы контур проходил через те же Vi-C (сдвиг на центр).
  - Поворот: используется тот же θ, что и у Matter.js body.
  - Размер: спрайт масштабируется в рантайме так, чтобы его bbox совпал с bbox фигуры (или спрайт рисуется сразу в масштабе 2x от стандартных координат).
  - Несимметричные фигуры (triangle/pentagon): ключевое условие — совпадение локальных вершин Vi и их порядка; тогда centroid и поворот обеспечивают точное наложение.
